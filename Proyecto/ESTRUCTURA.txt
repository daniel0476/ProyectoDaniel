🗄️  BASE DE DATOS (7 TABLAS)
════════════════════════════════════════════════════════════════════════════════

1. USUARIOS
   ├─ ID_usuario (PK, autoincrement)
   ├─ nombre, apellidos, email (UNIQUE), teléfono
   ├─ contrasena (BCRYPT hash)
   ├─ rol ('cliente' o 'admin')
   ├─ fecha_registro (TIMESTAMP)
   └─ activo (0 o 1)

2. BARBEROS
   ├─ DNI_barbero (PK)
   ├─ nombre, apellidos, teléfono, especialidad
   ├─ experiencia_anos, horario_inicio, horario_fin
   ├─ dias_atiende (días laborales)
   └─ activo (0 o 1)

3. SERVICIOS
   ├─ ID_servicio (PK, autoincrement)
   ├─ nombre, descripcion
   ├─ precio (DECIMAL)
   ├─ duracion_minutos
   └─ activo (0 o 1)

4. CITAS
   ├─ ID_cita (PK, autoincrement)
   ├─ fecha (DATE), hora (TIME)
   ├─ DNI_barbero (FK), ID_usuario (FK), ID_servicio (FK)
   ├─ estado ('pendiente', 'confirmada', 'completada', 'cancelada')
   ├─ precio_final (DECIMAL)
   ├─ notas_cliente, notas_admin (TEXT)
   ├─ fecha_creacion, fecha_modificacion (TIMESTAMP)
   └─ Indexes en fecha, estado, usuario

5. HORARIOS_DISPONIBLES
   ├─ ID_horario (PK, autoincrement)
   ├─ DNI_barbero (FK)
   ├─ fecha (DATE)
   ├─ hora_inicio (TIME)
   └─ hora_fin (TIME)

6. CONFIGURACION_SISTEMA
   ├─ nombre_barberia (VARCHAR)
   ├─ email (VARCHAR)
   ├─ horario_apertura (TIME), horario_cierre (TIME)
   ├─ duracion_slot_minutos (INT)
   └─ contacto (VARCHAR)

7. HISTORIAL_ACCESO
   ├─ ID_acceso (PK, autoincrement)
   ├─ ID_usuario (FK)
   ├─ fecha_acceso (DATETIME)
   ├─ ip_address (VARCHAR)
   └─ navegador (VARCHAR)
